Better clips behind your songs.

- **Only official clips:** the video behind a song now comes only from the artist, their VEVO channel or their label. Fan uploads, teasers, phone-format shorts and still covers no longer appear.
- **More clips found:** clips that labels host (for example on Atlantic Records or Fueled By Ramen) and official visualisers now show up too. When a song has no music video, a session or live performance by the artist can stand in.
- **No clip, no problem:** when nothing official exists, the moving colours of the cover stay behind the song, as before.
- Clips chosen by earlier versions are looked up once more with the new rules.

## Install

Download **`SoundLibertApp-win-Setup.exe`** below and run it. If you already have SoundLibert, it updates itself: a card appears in the app, and **Restart now** installs the update.

**Requirements:** Windows 10 (1809) or newer, 64-bit. Signing in needs the Microsoft Edge WebView2 Runtime, which Windows 11 already includes. Windows "N" editions also need Microsoft's Media Feature Pack, or songs cannot play.

> The installer is not code-signed yet, so Windows SmartScreen may warn about an unrecognised app. Choose **More info → Run anyway**.
